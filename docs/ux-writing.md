# UX Writing & Tone — Thwap Hockey Training

**Audience: the player, ages 8–13.** Not the parent, not the coach. Write like a
cool older teammate who wants them to get better and have fun. Rooted in
`child-centered-design.md`: meet kids where they are, encourage, never pressure.

## Measured rubric (the target, verified per pass)
- **Average sentence length ~6.5 words** across a page. This is the number that
  keeps it readable for ages 8–13. Check it, do not eyeball it.
- **Steps are action-first:** the step opens with what to do, not with setup prose.
- **Bold labels on every step** so a kid can scan the page in one pass.
- **Split any long sentence** into two short ones. One idea per sentence.
- **Watch for automated-swap artifacts** when copy is edited in bulk: repeated
  words ("cone or cone"), broken articles ("an ready position"), and leftover
  fragments. Read the final copy, do not trust the swap.

## Voice
- **Encouraging, never bossy.** Cheer effort, not just results.
- **Short and punchy.** A 9-year-old skims — one idea per line.
- **Active, doing-focused.** Start with a verb: "Head up," "Stick the landing,"
  "Pick your goals."
- **Fun, a little bold** (Bigfoot energy) but always kind. Confidence, not trash talk.

## Rules
- **Reading level ~grade 3–4.** Common words. Short sentences: aim for a
  ~6.5-word average, and never run past ~12 in a single sentence.
- **No jargon or corporate words.** Avoid: "activities," "development," "metrics,"
  "modules," "optimize," "assigned tasks." Say: "drills," "work," "today's list,"
  "practice."
- **Second person.** "You," "your." Never "the player should…".
- **Positive framing.** "Nice work!" not "You only did 3." Falling short is
  "let's finish strong," never "you failed."
- **One exclamation max per screen.** No ALL-CAPS shouting.
- **Emoji: light touch.** Fun accents, not every line. (Welcome here — it's the
  kids' app.)
- **Numbers as digits** ("4 goals," "20 min," "20 seconds / sequence") — easier to
  scan.

## How-to steps (the format that ships)
- Break a drill into **short, scannable numbered steps** — never a run-on paragraph.
- Each step leads with a **bold label** then the detail, e.g.
  **1. Set up:** mark a square and number the corners 1, 2, 3, 4.
  (The number and the label both render bold.)
- Spell out anything a kid can't picture from words alone; pair with a video when
  the coach supplies one.

## Content integrity (non-negotiable)
- **Never fabricate** drills, reps, how-to specifics, videos, or a team motto.
  Build only from what the coach provides.
- For team-specific named drills (e.g. "Will's Squares," "McDavid's") use the
  coach's own definition; don't invent how they work.
- When content is pending, write the **real structure awaiting content**, never a
  fake or "coming soon" dead end.

## Examples (do → don't)
| Screen | Say this | Not this |
|---|---|---|
| Home headline | Today's training | Select a development activity |
| Home sub | Three parts you can do at home. About 30–45 min. | Assigned daily training modules |
| Drill cue | Head up. Soft hands. Move the puck. | Maintain visual awareness while controlling the puck |
| Step | **Both feet:** hop 1-2, 1-3, 1-4. 20 seconds each. | Perform the agility sequence for the prescribed interval |
| Done state | All caught up! Go play. | You have completed 100% of assigned tasks |
| Empty | Nothing yet — rest up! | No activities are currently assigned |
| Not built | Soon | Feature unavailable |
| Leaderboard | Who's putting in the work? | Team completion analytics |
| Button | Mark done | Submit |

## Titles & labels
- Keep drill names playful and short (e.g. "Frank's Tic-Tac-Toe," "Will's Squares
  (4-sq Drill)").
- Section labels plain: "Today," "Today's Dryland Mix," "How points work."
- Time and effort always visible and concrete: "about 15 min," "20 seconds /
  sequence," "6× (2 reps)."
